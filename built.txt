ITER: what was built, step by step
==================================

This is the build record. It is compiled from the project's Git history (every change is a dated
commit on GitHub: https://github.com/dfxuan288/iter-app/commits/main) and compared with the steps
in plan.txt, section 9.

Checks: before each step was joined to the main version, the type check, lint and all automated
tests were run in both the app and the backend. Since Step 0, GitHub has also run them on every push
(the Actions tab). Each feature was also tried in a browser before it was published.


Step 0. Foundations                                        13 Oct 2026
  Built:    Expo + TypeScript app with five tabs, design colours and sizes in one file, backend
            with a health check, automatic checks on GitHub, README. A design pass the same day:
            light aqua style, Outfit font, destination photos on Home.
  Checks:   type check, lint, tests passed; checks also run on GitHub from this step on.
  Compared with plan.txt: on track.

  Built:    Safe-to-spend maths as tested functions, demo trip, Home screen with spent, remaining,
            status, daily bars and categories, plan-a-trip form.
  Checks:   type check, lint, tests passed.
  Compared with plan.txt: plan adjusted: hosting moved from AWS to Vercel + Supabase the same
            night (lecturer's recommended setup).
