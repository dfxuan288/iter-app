ITER: list of dependencies
=========================

ITER is written in TypeScript and runs on Node.js, so its dependencies are npm packages,
not Python packages. They are installed from package.json (exact versions are locked in
package-lock.json):

  npm install                    (backend, in the project folder)
  npm --prefix mobile install    (frontend, the app in mobile/)

Runtime
-------
Node.js 22 or newer (tested on 24)
npm (comes with Node.js)

Online services (no installation; accounts and keys)
----------------------------------------------------
